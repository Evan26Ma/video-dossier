# 平台采集（B 站）

只用**匿名公开接口**：`buvid3/buvid4` 设备指纹 + wbi 签名，**不使用登录态或 cookies**。下面的路径与坑都是实测结论。

## 一、能拿到什么

| 数据 | 接口 | 备注 |
|---|---|---|
| 标题 / UP / 发布 / 时长 / 分P / 分辨率 / 分区 / 标签数 | `x/web-interface/view?bvid=` | 一次拿到视频级全部字段 |
| 播放 / 点赞 / 投币 / 收藏 / 分享 / 评论 / 弹幕 / 排名 | 同上 `data.stat` | **累计值**，只代表采集瞬间 |
| 标签详情 | `x/tag/archive/tags?bvid=` | 返回顺序无语义，别当排名 |
| UP 粉丝 / 关注 | `x/relation/stat?vmid=` | 瞬时值 |
| 分P 的字幕轨 / 官方章节 | `x/player/v2?bvid=&cid=` | `subtitle.list`、`view_points`；多数录播两者都是空 |
| 同时在看（全站 / 本视频） | `x/player/online/total?bvid=&cid=` | 瞬时值，波动大，别当热度 |
| 弹幕列表 | `x/v1/dm/list.so?oid=<cid>` | 返回 XML；空壳说明 0 条 |

## 二、拿不到什么

| 数据 | 原因 |
|---|---|
| 完播率、留存曲线、观众画像、涨粉、分P 播放占比 | 平台不公开 |
| 评论全量 | 匿名可见性受限（见下） |
| 逐日增长 | 需要自行定时采样；单次快照无法还原 |
| 弹幕原文（当页面弹幕为 0 时） | 数据不存在；标题里的「含弹幕」可能是烧录在画面里 |
| 1080P60 等高码率流 | 需要大会员 |

## 三、匿名会话怎么建

1. 先请求一次 `https://www.bilibili.com/` 暖 cookie。
2. `x/frontend/finger/spi` 取 `data.b_3` / `data.b_4`，作为 `buvid3` / `buvid4` 带上。
3. `x/web-interface/nav` 取 `wbi_img.img_url` / `sub_url`，各取文件名（去扩展名）得到 `imgKey` / `subKey`。
4. `mixinKey = mixinKeyEncTab(imgKey + subKey)`（一张 64 项的固定重排表）。
5. 签名：参数按 key 排序 → 值去掉 `!'()*` → `urlencode` → 拼 `wts` → `w_rid = md5(query + mixinKey)`。

Node 侧实现见 `scripts/vd_config.mjs` 同目录的 `fetch_meta.mjs`（含 MIXIN 表），可直接抄。

## 四、实测的坑

1. **`ps` 上限 20**。评论接口写 `ps=49` 返回 `-400 ps out of bounds`。
2. **评论的匿名可见性有硬上限**：
   - `x/v2/reply/wbi/main` → 未登录 `-403 访问权限不足`；
   - `x/v2/reply/main`（带 wbi）→ `code=0` 但 `cursor.is_end=true`，只给少量楼层；
   - 老端点 `x/v2/reply?sort=2` → 同样只给少数楼层，`page.count` 却是全量（含审核中/未公开）。
   差额无法匿名取到。**结论**：要么把「只采到可见楼层」写进口径，要么直接不采评论。
3. **弹幕为 0 要三方验证**：`stat.danmaku`、弹幕列表接口、客户端下载的弹幕文件（ASS 里 `Dialogue:` 行数）。三者一致才能下结论。
4. **画质阶梯**（用 `yt-dlp -F` 先看体积再决定）：
   - 视频：`30016`(360P) / `30032`(480P) / `30064`(720P) / `30080`(1080P)；1080P60 需大会员；
   - 音频：`30216`(≈64k) / `30232`(≈132k 前缀) / `30280`(更高)；**要音频就用 m4a 音轨**，别下整段视频再抽。
   - `fnval=1` 的 durl 单文件最多到 720P。
5. **一次序列采完**：视频新发布时计数分钟级变化，分几次抓会让同分母比率失真。所有字段共用一个 `collectedAt`。
6. **语义未定义的字段原样记录**（例：`copyright=3`），在口径里写「未定义、不解读」。
7. **请求间隔 700ms 起步**，失败重试 3 次并记录最终实抓条数。

## 五、本地文件模式

`media.kind = "local"` 时：

- `localAudio` / `localVideo` 给绝对路径，`bvid` 留空；
- `collect` 阶段跳过（没有平台数据），`verify.py` 的平台断言自动跳过；
- 转写文件名用音轨文件的 stem；
- 若只有视频，用 `ffmpeg -i <video> -vn -c:a copy <audio>` 抽音轨，别重新编码。

## 六、合规

- 只用匿名公开接口，不用登录态、不用 cookies、不绕过付费内容、不去水印。
- 音轨与转写只为本地分析，不二次分发；产物里注明来源 BV 号与采集时刻。
