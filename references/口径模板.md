# 统计口径模板

把这份复制到 run 根目录的 `README.md` 里逐项填写。**口径是交付物，不是文档装饰**：没有它，产物就只是不可用的数字。

填写原则：
- 每个数字都要能回答四件事：**来自哪里**（接口/文件 + 字段）、**怎么算**（公式）、**什么时候采的**（快照时刻）、**误差在哪**（已知限制）。
- 拿不到的指标写进「不可得清单」，**不估算、不编造**。
- 口径与产物同目录、同版本；改了算法就改口径并注明日期。

---

## 一、快照语义

> 例：所有平台计数都是累计值，只代表 `collectedAt = 2026-10-03 00:02:34 (+08)` 那一个瞬间，没有时间序列。视频发布仅 45 分钟，因此不使用「播放/小时」（分母太小会被放大），改用「播放/发布分钟」并标注不具代表性。

最少要写：采集时刻（带时区）、是累计值还是瞬时值、哪些比率因此不可比。

## 二、字段来源表

逐字段列 `API + 字段名 + 语义 + 单位`。产物里建议直接给一份长表 CSV（列：`scope, metric, value, source_api, note`），让口径与数据同源。

语义未定义的字段（如某些版权/分区字段）原样记录并注明「语义未定义，不做解读」。

## 三、派生公式

```
互动率   = (点赞 + 投币 + 收藏) / 播放
赞播比   = 点赞 / 播放
藏播比   = 收藏 / 播放
评播比   = 评论 / 播放
投币/点赞 = 投币 / 点赞
```

**分母必须来自同一次快照**；跨快照混算会失真。

## 四、空缺与「零」的区分

- 「接口返回 0」与「接口未提供」是两回事，要分别标注。
- 「零」要能交叉验证时给三方证据（例：弹幕 0 = `stat.danmaku`=0 + 弹幕列表接口空响应 + 客户端下载文件行数为 0）。

## 五、时长口径

基准分P/音轨、ASR 时长与源时长对账偏差（阈值 <1%）、多分P 时哪一个是基准、其余分P 为何不进统计。

## 六、字数口径

```
han          = [\u4e00-\u9fff]
latinDigit   = [A-Za-z0-9]
punct        = 其余非空白字符
withPunct    = han + latinDigit + punct
withoutPunct = han + latinDigit
字/分钟      = withoutPunct ÷ (时长/60)
```

若转写缺中文句号，明确写「标点仅 ASCII 逗号」。

## 七、停顿口径

```
gap = 下一段.start − 上一段.end
≥ 阈值（默认 1.5s）记一次停顿，分档 [1.5,3) / [3,10) / [10,30) / ≥30
```

**必须写明的限制**：开启 VAD 后段内停顿被合并，停顿次数是**系统性低估**。

## 八、说话占比

`Σ(段.end − 段.start) / 总时长`；空白占比 = 1 − 说话占比。开头/结尾的纯静音要用音量检测（如 ffmpeg `volumedetect`）验证是真静音，而不是 ASR 丢字。

## 九、词频口径

分词器与版本、停用词表来源与长度、最小词长、n-gram 的 n 范围与最小次数、是否做极大化过滤。**复读伪影**要做折叠对照并把影响幅度写出来。

## 十、术语口径

词表文件路径、类别、**同类内最长词优先且不重复计数**、跨类别是否可重复计。若词表里混有「既是专业术语又是日常词」的条目（例：可能、发展、规律），必须写明命中数被高估。

## 十一、大纲口径

- 一级主题 / 二级知识点各自的定义与数量。
- 边界规则（例：取该条目第一句话所在行的行首秒数，宁晚不早）。
- 官方是否有章节标记；没有的话必须写「大纲是判读结果，非官方结构」。
- 覆盖度两种算法都写：
  - **tiledCoverage**：主题按「下一个主题起点」铺满时间轴后的并集占比（口径值）；
  - **annotatedSpan**：首末知识点跨度占比（实测值）。
- 空档审计阈值与结果（例：≥420s 空档 0 处）。

## 十二、纠错口径

- 替换是**纯字符串操作**，不改句意、不删句、不重写 → 因此可复现。
- 裁决规则（例：错串不是词典词默认采纳，是真词默认拒绝并人工逐条裁决）。
- 采纳/拒绝条数与命中次数；拒绝理由逐条记录。
- **长度守恒校验**结果（`charDelta == charDeltaExpected`）。
- **clean 稿不参与任何统计**。

## 十三、画面口径

源格式与画质、抽帧频率、去重算法与阈值、OCR 分层抽样规则、帧时间戳精度、OCR 引擎与版本、页面文本块分类是启发式而非人工标注、屏幕数字未逐项校对。

## 十四、不可得清单

| 拿不到的指标 | 原因 |
|---|---|
| 完播率 / 留存曲线 | 平台不公开 |
| 涨粉 / 观众画像 | 平台不公开 |
| 弹幕原文 | 页面弹幕为 0，或属登录态数据 |
| 逐日增长 | 需要自行定时采样，单次快照无法还原 |
| 分P 播放占比 | 平台不公开 |
| 评论全量 | 匿名接口只暴露少量楼层 |
| 屏幕精确文字 | OCR 有错字，且未人工逐项校对 |

## 十五、降级声明

本次跑动中所有**未达标**的地方都要写在这里（例：OCR 看板命中率 37.6%、ASR 设备回退到 CPU、某切片代理重派一次）。**宁可写出来，不要静默略过。**
