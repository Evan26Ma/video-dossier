# 杂志版文案文件（`content/magazine-copy.json`）

杂志风报告（默认样式）由两部分合成：

- **数据**：表格、数字、图表、目录、文件索引、质量读数 —— 由 `make_magazine.py` 从 run 产物里读，**不要手写**。
- **文案**：标题句、导语、一句话结论、清单、引用块、能做什么/不能做什么 —— 由本文件提供。这些是**编辑判断**，从数据推不出来，只能由 agent 写。

缺这个文件也能出片，只是文案部分走兜底（标题句由数据拼、结论块为空）。**要让它像人写的，就必须写这个文件。**

## 最小可用

```json
{
  "coverline": "一场 2 小时 43 分的录播，其实<span>有 56% 的时间在讲题</span>",
  "verdict": {
    "tag": "一 句 话 结 论",
    "paras": [
      "这是一场 <b>2 小时 43 分</b>的录播：<b>带着做题占 56.1%</b>，开课铺垫 13.4%。",
      "整场只有开头 <b>137 秒</b>是安静的，其余 <b>95.3%</b> 的时间都有人在说话。"
    ]
  }
}
```

## 字段全集

| 字段 | 说明 |
|---|---|
| `htmlTitle` | 浏览器标题；默认「<视频标题> · 数据解读报告」 |
| `logo` | 左上角刊名（支持内联 HTML，例：`政治<em>·</em>27`） |
| `flagMeta` | 右上角事实行数组（每行一条）；留空则自动生成（来源/分P/时长/UP/发布日期/采集时刻） |
| `deck` | `{vol, label, tagline}` → `VOL.01 / 数 据 解 读 / 只统计，不评价课` |
| `over` | hero 上方的小字（默认「总 览 · 一 眼 看 完」） |
| `cover` | 封面图相对路径（留空则不显示；例 `cover/video-cover.jpg`） |
| `coverline` | **主标题句**；默认由数据拼兜底 |
| `bignums` | hero 的 4 个大数字：`[{value, unit, hot, title, note}]`；留空按数据自动挑 4 个 |
| `tshint` | 时间戳可点的提示；留空自动生成（仅 B 站来源） |
| `verdict` | `{tag, paras[]}` → 深色「一句话结论」块 |
| `watermark` | 页面水印文字（留空不出） |
| `kindLabels` | 大纲 `kind` → 展示名。例 `{"例题":"带着做题","互动":"和观众互动"}` |
| `sections` | 见下（按 `structure` / `language` / `screen` / `quality` / `usage` 分组） |
| `questions` | 「后续能做什么调查」表格行 `[[问题, 去哪找数据], ...]` |
| `cannot` | 「这些事它做不了」清单 |
| `footer` | 页脚三段文字 |

### `sections.<名>` 通用字段

`kicker`（左上小标签，如 `01 · 讲了什么`）、`title`（大标题，可含 `<em>` 强调）、`lead`（导语）、
`ticks`（要点清单数组）、`blockquote`（引用块）、`sub2/sub3/sub4`（小节标题）、各种 `*Caption`（表格/图注）。

### 各节专有

- `structure`：`timelineRows`（时间线列几行，默认 12）
- `language`：`figCaptions`（图注，键为图文件名或序号）、`rhythmWords`（词频条，默认取 top10）、
  `catchphrases`（口头禅，默认取 top10）、`rhythmNote`
- `screen`：`cards`（关键数字卡，默认自动从屏幕数字里挑 `a/b` 分数对）、`stateRows`（屏幕状态列几行）
- `quality`：`ticks`（补充说明）
- `usage`：`questions` / `cannot` / `files`（文件索引，留空自动生成）

## 写法约定

1. **允许内联 HTML**：`<b>` `<em>` `<span>` `<code>` `<br>` 都可以用——它们是排版手段。
2. **`{ts:秒}`** 会被替换成可点击的时间戳。例：`在 {ts:368} 讲了水区旱区`。非 B 站来源会退化成纯文本。
3. **数字不要硬编码进文案**：能由数据生成的（计数、时长、占比）就让它生成；确需在句子里点名时，
   从产物里抄准确值，并记住口径（尤其是「百分比的分母是什么」）。
4. **一句话结论两个自然段就够**：第一段讲是什么，第二段讲最反直觉的那个发现。
5. **不要评价内容好坏**：杂志风是「把数据讲清楚」，不是打分。
